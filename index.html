系统提醒

提醒保存在手机，关闭 App 后仍会通知；网页版只在页面打开时提醒。

后台保活 · 提醒通知靠它

系统可能限制后台活动，按下面设置可减少漏提醒
  1. 电池：设置 → 电池 → 应用耗电管理 → 时序 → 选「不限制 / 允许后台活动」
  2. 自启动：设置 → 应用 → 时序 → 自启动 / 关联启动 → 打开
  3. 加锁：最近任务里把时序「加锁」，别一键清理
  4. 通知：允许时序发通知，否则查到也推不出来
  5. 精确闹钟：设置 → 应用 → 特殊权限 → 闹钟和提醒 → 允许时序

改完可以回来说「立即检查」验证一次：能查到活动列表就说明后台通路是好的。
