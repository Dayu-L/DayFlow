# 时序 DayFlow

一个内置日程智能体的本地时间管理 Web App。**竖向时间轴，色块的上边缘就是开始时刻。**

无需安装、无需构建，双击 `index.html` 即可使用。推荐 Chrome / Edge。

Android 手机：装根目录的 `DayFlow-1.23.0.apk`。原生壳说明和签名信息见 [`android/README.md`](android/README.md)。

## 快速开始

1. 双击 `index.html`，或双击 `启动.bat`。
2. 首次打开会放入几条示例日程。对左侧 Agent 说一句：

   > 明天下午 3 点产品评审 1 小时，在 3 楼会议室

3. 日程会自动落到时间轴上；如果日期变了，日历会自动跳过去。

## 已实现的功能

### 时间轴

- 24 小时竖向时间轴，色块的**上边缘精确对齐开始时刻**，高度表示持续时长
- 时间轴左侧有开始点，把色块与具体时刻连起来
- 同一时段重叠时自动分栏
- 当前时刻红线，每 30 秒自动刷新
- 点击空白时间格新建（吸附 15 分钟）
- **选中再操作**：第一次点色块只选中，再点一次打开编辑；避免误触
- 选中后色块右上角会出现「完成」按钮，第一次点击就能直接勾完成 / 取消完成，不用再点操作条
- **调整模式**：开关会记住；开启后拖动已选中的色块改时间、拉底边改时长
- **缩略模式**：把 24 小时压进一屏，适合看一整天的课表；点「缩略 / 标准」切换
- **月历跳转**：点日期标题或日历图标打开月历，可跨周、跨月直接跳转；周条两侧也有上一周 / 下一周
- 周条、前后翻日、回到今天
- 调整模式下悬停色块右上角可勾选完成
- 当天事项数、规划时长、完成率、分类图例
- 每个日程可以设置提醒：准时 / 提前 5 / 10 / 15 / 30 / 60 分钟 / 提前 1 天
- **DDL 截止标记**：截止事项显示为红色横线 + 右端旗标，不占用时间块；点击即可编辑
- 地点 / 备注直接显示在时间轴色块里；手机端不再隐藏，选中后操作条也会显示完整备注
- 重复日程会自动合并；短日程不再因最小高度互相压住
- Agent 支持「备注：带上电脑」这种写法，会把备注写进日程
- **日 / 周视图**：时间轴上方可切换；周视图把周一到周日 7 天并排放在同一页
- 周视图会高亮今天、画出当前时刻线、显示每天的日程块和 DDL 截止线；顶部统计切换为整周数据
- 标准模式显示开始时间、标题，空间足够时显示地点；缩略模式把整周 24 小时压进一屏，保留标题，并用淡色底区分今天和周末
- 点周视图的日期头会进入那一天的日视图；点某天的空白时间格会按那天的日期和时间新建日程
- **Agent 快捷输入栏**：日历页时间轴上方直接输入一句话即可添加日程，不用切到 Agent 面板；手机端停留在日历页也能快速录入

### 功能页

- 新增「功能」页：把任务、DDL、顺延、专注、课表、分类、模板和设置按用途分组
- 日历页只保留时间轴和常用操作：今天、新建、调整、日 / 周、标准 / 缩略
- 桌面端点右上角宫格图标进入；手机底部导航是「日历 / 功能 / Agent」
- 功能卡片上会显示待处理数量或当前状态（任务数、DDL 数、课表节数、通知状态）
- 「本周复盘」会直接切到 Agent 并发送复盘指令；「返回日历」或手机返回键可回到时间轴

### 主题外观

- 九套主题：**HUD**（默认，科幻舰载界面）、**视差**（叙事光影叠层）、**空间**（3D 悬浮界面）、**极光**、**玻璃**、**纸白**、**墨夜**、**暖砂**、**松林**
- 右上角调色板按钮随时打开主题面板；功能页 →「主题外观」也可以切换
- 点一下立即生效，不需要刷新；选择会保存在本机，下次打开自动恢复
- 所有主题共用同一套字体、字号、间距、圆角和布局；只改变配色、背景、阴影和玻璃质感
- 深色主题下日程色块、周视图、DDL、弹窗和输入框都会同步换色
- **HUD**：深空、青色发光、四角定位括号、扫描线和等宽标签；星点 / 网格随鼠标或滚动轻微视差
- **视差**：暖色暗调、衬线标题、光影层与地平线错位，带电影暗角；适合叙事感的日程浏览
- **空间**：浅紫蓝、悬浮玻璃卡片、大圆角和 3D 阴影；鼠标悬停卡片会轻微抬升
- 主题只改变外观，不影响日程、任务和提醒数据

### 桌面小组件（APK）

- 4×2 桌面小组件「时序 · 今日日程」
- 显示今天的日期、下一项 / 进行中的日程，以及后面最多 2 项安排
- 底部显示未完成 DDL、任务收件箱数量
- 当天日程超过 3 项时，右下角出现 `‹ 1/3 ›` 翻页按钮，每页显示 3 项
- 点小组件任意日程会直接打开 DayFlow 并定位到该日程
- 小组件颜色跟随当前主题：墨夜 / HUD / 极光 / 视差用深色底，其余用浅色底
- 添加方式：长按桌面空白处 → 小组件 → 时序 · 今日日程；也可以从功能页 →「桌面小组件」请求添加
- 日程变化或打开 App 时会立即同步；系统每 30 分钟刷新一次。跨天后如果没打开 App，小组件会提示打开 DayFlow 更新今天日程

### 提醒通知

- APK 使用原生 `AlarmManager` + `NotificationManager`，**关闭 App 后仍会提醒**；重启手机、修改系统时间或更新 App 后会自动重排
- 点击通知会直接打开对应日程
- Android 13+ 首次使用需要点设置里的「允许通知」；Android 12+ 如果没有精确闹钟权限，会显示「精确提醒设置」入口
- 网页版只在页面打开时工作：有通知权限就用系统通知，否则在页面内弹出提醒条

### 内置 Agent

- 本地中文解析引擎，**离线可用**，不需要 API Key
- 日期：今天 / 明天 / 后天 / 下周三 / 11 月 5 日 / 2026-11-06 / 3 天后 / 周末
- 时间：上午 / 下午 / 晚上、3 点半、15:30、15:00-16:30、下午 3 点到 5 点
- 时长：1 小时 / 一个半小时 / 30 分钟 / 两小时
- 地点：`在 3 楼会议室`、`@会议室 B`、`地点：xxx`
- 自动识别分类：工作 / 学习 / 运动 / 生活 / 社交 / 休息
- 没说具体时间时，按“上午 / 下午 / 晚上”或当天空档智能排入
- 支持一句话拆多条（逗号 + 时间、分号、换行）
- Agent 输入框不设字数上限，长文本、整段课表可以直接粘贴
- 支持重复：每天 / 工作日 / 每周一三五 / 每周末（生成未来一年的日程，并归入同一个重复系列）
- 重复系列可以在弹窗里选「整个系列」统一改时间 / 标题 / 内容，或直接删除整个系列
- 支持查询、删除、改期
- **找空档**：说「这周哪里能塞下 2 小时」「周五下午有空吗」，会列出可用时段和长度
- **语音输入**：支持的浏览器 / WebView 会在输入框旁显示麦克风，按住说话，识别结果直接进输入框
- **图片识别**：支持选择、粘贴、拖入图片（最多 3 张），交给支持视觉的大模型提取日程；本地离线模式不能识图
- 接入任意 OpenAI 兼容大模型（DeepSeek / Ollama / 视觉模型），失败自动回退本地

### 更懂上下文

- 改动 / 删除时可以接上一轮：例如刚新增「产品评审」，接着说「改成4点」「推迟半小时」「取消它」
- 会优先使用时间轴上当前选中的色块作为操作对象
- 「高数」可以匹配「高等数学」；匹配到多项时会先问你要改哪一项，不会直接猜
- **短期记忆**：大模型模式会带上最近 8 轮对话；本地模式会记住当前选中 / 上一门系列课
- 例如刚排完「1-16周 周三第1-2节 高数」，接着说「再加第3-4节 英语」，会自动沿用同一个星期和周次
- 说「改成4点」「推迟半小时」「取消它」会作用到刚才的日程或当前选中的色块
- 支持按课堂查询：「高数什么时候上课」「产品评审几点」「这周有几节课」
- 「全部清空」会清空**所有日期**的日程、重复系列和课表节次，不受当前周限制；「清空全部日程」只清日程，「清空课表」只清节次
- 「清空本周 / 下周 / 未来一周」只清对应周范围
- 「把全部会议删了」只删除匹配的会议，不会误删其他日程

### 长文本与批量

- 粘贴多行文本时会按换行拆分，不会再把整段压成一条日程
- 单次最多处理 **3000 项**；聊天里列出前 20 项，其余直接写入时间轴
- 支持一次粘贴整周 / 整学期课表，多门课可以用换行或「，第3-4节」拆开
- 「1-16周」会展开成整学期系列；大模型模式也只需返回一门课一个 addSeries，不会只排一周
- 图片识别 / 长文本里的周次必须以学期第 1 周为基准，不会拿今天反推
- 多行课表会继承上一行的星期 / 周次，避免第二行被排到今天或错误日期
- 重复添加同一日程会自动合并，不会在时间轴上出现两块一样的色块
- 15 分钟以内的短日程不再被最小高度撑开，减少视觉重叠
- 批量写入只落一次本地存储，大清单不会逐条卡顿

### 课表节次

- 设置 → 课表节次，先录入第 1 节到第 N 节的开始 / 结束时间，也可以用「常用 12 节模板」再改
- 必须填「学期第 1 周周一」才能处理「1-16周」；不填会提示先补填，避免把第 1 周对齐到今天
- 之后直接这样说：
  - `周三第1到2节 高等数学`
  - `1-16周 周三第1-2节 高等数学`
  - `1-16周单周 周三第1-2节 数据库`
  - `每周五第3-4节 大学物理`
  - `第1、2节 英语`
  - `明天第5节 实验课`
- Agent 会把「第几节」换算成具体时间，自动识别日期、标题、分类，并在备注里记下「第1–2节」
- 支持按周次生成系列：`1-16周`、`1-8周`、单周 / 双周；已过去的周次会自动跳过；周次始终以学期第 1 周为基准
- 大模型模式下一门固定课只返回一个 `addSeries`，由本地展开整学期，不会只排一周
- 没有设置课表时，Agent 会提示并直接打开课表设置；节次超出已设置范围也会提示
- 支持阿拉伯数字和中文数字：`第1-2节`、`第三到四节`、`第1、2节`

### 任务收件箱 + 自动排程

- 顶栏「任务」按钮打开收件箱；也可以对 Agent 说「任务：写周报 2 小时，周五前」或「把买牛奶放进收件箱」
- 任务记录预计时长、优先级、截止日期；收件箱按优先级和截止日期排序
- 点「自动排程」先预览，再点「应用排程」写入时间轴
- 排程会避开已有日程、午休（12:00–13:00）和夜间，可用窗口是 09:00–12:00、13:00–18:00、19:00–21:30

### DDL 截止事项

- 时间轴上方的「DDL」按钮打开 DDL 列表；列表底部可以新建，时间轴上的红色标记可以编辑；也可以直接对 Agent 说：
  - `ddl：交实验报告 周五 23:59`
  - `ddl 高数作业 明天 17:00`
  - `ddl 有哪些`
  - `完成 DDL：交实验报告`
  - `把 DDL：高数作业 改到周六 18:00`
  - `删除 DDL：高数作业`
- DDL 只记录截止日期和时刻，**不会占用时间轴上的时间段**，而是显示成一条红色横线和右端旗标
- 点「DDL」按钮打开列表，按「已逾期 / 今天 / 本周 / 以后 / 已完成」分组；左侧圆圈直接标记完成，点条目标题会跳到当天并打开编辑
- 同一天有多个 DDL 时，旗标会自动上下错开，避免互相压住
- 点击标记可改标题、日期、时间、备注，或勾选完成 / 删除
- 每个 DDL 可以填「预计投入」；列表会计算截止前可用空档，不够时标红「空档不足」，顶部日期说明也会提示
- 「DDL」按钮上显示未完成数量；有逾期时会加深提示
- 已完成 DDL 仍然保留在时间轴上，但会变淡并划掉

### 今日收尾 / 顺延

- 时间轴上方的「顺延」按钮打开收尾面板，列出当前日期没完成的日程
- 勾选要挪的日程，选「明天同一时间」或「下一个空档」；冲突时会自动找下一个可用时段
- Agent 也可以直接说「把今天没完成的顺延到明天」
- 顺延后可以用提示条上的「撤销」恢复

### 专注计时

- 顶栏时钟按钮开始专注，可选 15 / 25 / 45 / 60 / 90 分钟，也可以关联当天日程
- 开始后顶部出现倒计时条，可以随时结束；到点会提醒并自动记录
- 实际专注时长会累加进关联日程的「实际」时长，周复盘里也会用到

### 每日简报 / 周复盘

- 每天第一次打开（5 点后）会自动生成一条今日简报：事项数、总时长、下一项、最长空档、收件箱任务
- 点快捷指令「本周复盘」，或对 Agent 说「本周复盘」，会总结本周安排、完成数、实际专注、时间最多的分类、冲突和收件箱

### 其他

- 聊天、日程、任务、DDL、专注记录保存在本机 `localStorage`
- Agent 操作可撤销
- 导出 `.ics`，可导入系统日历
- 手机 / 平板响应式布局，手机端右下角有 Agent 悬浮入口

### 数据与个性化

- 设置 →「数据与备份」可以导出 / 导入全部 JSON；JSON 备份包含日程、任务、DDL、分类、模板和专注记录，**不包含 API Key**
- 每天首次打开自动保存一份快照，保留最近 3 份；可以在设置里选择日期恢复
- 支持导入 `.ics`：单次日程和简单的每日 / 每周重复会展开；复杂重复规则或 `TZID` 可能只导入首次，导入前建议先导出备份
- 「分类与颜色」可以改名、换色、添加分类；改名会同步更新已有日程、任务和重复系列，使用中的分类不能删除
- 「日程模板」把当前日期的标题、时间、分类和备注保存下来，之后可以一键套用到当前日期
- 顶栏「顺延」和 Agent 的「顺延」都可以做今日收尾

图片：点输入框左侧的图片按钮，或直接粘贴 / 拖入截图，然后补一句：

```
把这张图里的日程都加进来
这张课表帮我排一下
```

图片识别需要「大模型」模式，且模型支持视觉输入；本地离线模式不能识图。

## 操作与快捷键

| 操作 | 说明 |
| --- | --- |
| 点击空白时间格 | 在对应时刻新建日程 |
| 点击色块 | 第一次选中，再点一次打开编辑 |
| 选中后的操作条 | 编辑 / 完成 / 删除 / 取消选择；有备注时显示备注 |
| 开启「调整」 | 开关会记住；开启后才能拖动 |
| 拖动已选中色块 | 改开始时间，保留时长 |
| 拖动色块底边 | 改结束时间 |
| 悬停色块右上角 | 调整模式下标记完成 / 未完成 |
| Tab 到色块后按 Enter / Space | 第一次选中，再按一次打开编辑 |
| 时间轴上方的「DDL」 | 新建 / 查看截止事项；点红色旗标可编辑 / 完成 / 删除 |
| 时间轴上方的「顺延」 | 把当前日期没完成的日程挪到明天或下一个空档 |
| 时间轴上方的「日 / 周」 | 切换日视图和周视图；周视图 7 天并排 |
| `W` / `D` | 切到周视图 / 日视图 |
| 周视图里的日期头 | 进入该天的日视图 |
| 周视图里的空白时间格 | 按该天日期和时间新建日程 |
| 输入框左侧麦克风 | 语音输入（需要浏览器授权麦克风；不支持时自动隐藏） |
| 设置 → 数据与备份 | 导出 / 导入全部 JSON、恢复快照、导入 `.ics` |

## 接入大模型（可选）

1. 点击左上角齿轮 → 选择「大模型」。
2. 填写 OpenAI 兼容接口：

   - DeepSeek：`https://api.deepseek.com/v1`，模型 `deepseek-chat`
   - Ollama：`http://localhost:11434/v1`，模型填本地模型名
   - 视觉模型（识图）：`gpt-4o`、`qwen-vl-max`、`glm-4v` 等支持图片输入的模型
   - 其他兼容 `/chat/completions` 的服务也可以

3. 填写 API Key（Ollama 可留空），保存。

说明：

- 接口必须是 OpenAI 兼容格式，最终请求 `${BaseURL}/chat/completions`。
- Key 只保存在本机浏览器的 `localStorage`，不会上传到别处。
- 如果接口不支持浏览器跨域，请求会失败，此时会自动回退到本地智能体，并在回复里说明。
- 本地模式完全离线，不依赖网络。
- API Key 输入框使用普通文本键盘，**不会唤起 Android 安全键盘**；默认用点号遮罩，点右侧眼睛可以查看/隐藏。
- **图片识别需要模型支持视觉输入**；图片会以 base64 发送到你配置的接口，不会存进本地数据（聊天里只保留缩略图）。网络失败或模型不支持视觉时，不会伪造识别结果。
- 图片会先压缩到最长边约 1400px，最多 3 张。

## 已知边界

- 重复日程用「未来一年的独立事件 + 系列 ID」实现，不是 RRULE；改整个系列或删整个系列会作用到所有实例，单独删除某一次只影响那一次。
- 暂不支持跨午夜日程（例如 23:00–次日 01:00）。
- DDL 只精确到分钟，暂不支持重复 DDL、子任务或自定义提醒；到点不会单独弹通知。
- ICS 导入支持单次日程和简单的每日 / 每周重复；复杂 RRULE、`TZID` 和例外日程可能只导入首次，导入前建议先导出 JSON 备份。
- 语音输入依赖浏览器 / WebView 的 SpeechRecognition 和麦克风权限；不支持时会自动隐藏麦克风按钮。
- JSON 全量备份不包含 API Key，导入后会保留当前设备上已填写的 Key。
- 日程模板套用到「当前查看的日期」，不会批量套用到整周。
- 周视图里的日程块不支持直接拖动；点色块会打开编辑弹窗。手机上周视图用色条展示日程，点色条查看详情。
- 课表只按连续节次换算；周次支持 `1-16周` / 单双周，暂不支持临时调课或自动避开教室冲突。
- 单次最多处理 3000 项日程；更大的清单请分批发送。
- 大模型单次能返回多少条 action 仍受模型输出长度限制，长清单优先用本地模式或分批处理。
- 网页版提醒只在页面打开时生效；需要在 App 关闭后提醒，请用 APK。
- 「调整」开关会记住上次状态；浏览模式下可以直接上下滑动时间轴，不会误拖色块。
- 缩略模式为了塞下一整天，色块很薄，适合查看；细调时间建议切回标准视图。
- 识图必须使用支持视觉输入的大模型，本地离线模式不能识图；图片会发送到你配置的接口。
- 大模型模式依赖接口允许浏览器 / WebView 跨域；不支持时会自动回退本地。
- 单机数据，不含账号和云同步。
